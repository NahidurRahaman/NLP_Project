# 🔠 OCR Text Recognition System

An **AI-powered OCR (Optical Character Recognition) web application** built with **Streamlit** and powered by a **FastAPI deep learning backend**.  
This system recognizes alphanumeric characters from images with a modern, interactive, and analytics-rich UI.

---

## 🚀 Features

- 📷 **Single Image OCR**
- 📁 **Batch Image Processing**
- 📊 **Analytics Dashboard**
- 📋 **Prediction History**
- 🎨 Beautiful modern UI with custom CSS
- 📡 Live FastAPI backend connection
- 🔤 Supports **0–9** and **a–z**
- ⏱️ Fast inference & responsive UI

# Activate virtual environment
